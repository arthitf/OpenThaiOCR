OpenThai OCR — โปรแกรมแปลงเอกสารสแกนเป็นข้อความภาษาไทย (ออฟไลน์)
=====================================================================

ใช้โมเดล iapp/OpenThai2.0-OCR-Text (Apache-2.0) ของ iApp Technology
รันบน CPU ไม่ต้องมีการ์ดจอ ไม่ต้องต่ออินเทอร์เน็ตตอนใช้งาน เอกสารไม่ออกนอกเครื่อง
รองรับ Windows และ Mac ชิป M (M1/M2/M3/M4)
พัฒนาโดย arthit.f


วิธีสร้าง exe (ทำครั้งเดียว บนเครื่อง Windows ที่ต่อเน็ต)
---------------------------------------------------------------------
1. ติดตั้ง Python 3.12 จาก https://www.python.org/downloads/
   ตอนติดตั้งให้ติ๊ก "Add python.exe to PATH"
2. แตก zip นี้ไว้ในโฟลเดอร์ที่ชื่อเป็นภาษาอังกฤษ ไม่มีเว้นวรรค เช่น  C:\OpenThaiOCR-App
3. ดับเบิลคลิก build.bat แล้วรอ (ครั้งแรกประมาณ 5–10 นาที)
4. ได้โปรแกรมที่  dist\OpenThaiOCR\OpenThaiOCR.exe

ตัวติดตั้ง (Setup.exe): ถ้าเครื่องมี Inno Setup 6 (https://jrsoftware.org/isdl.php)
build.bat จะสร้าง dist\OpenThaiOCR_Setup_v1.2.exe ให้ด้วย
  - ดับเบิลคลิกติดตั้งได้เลย ไม่ต้องเป็น admin
  - มีไอคอนใน Start menu / Desktop, เมนูคลิกขวา "อ่านด้วย OpenThai OCR" และถอนการติดตั้งได้จาก Settings > Apps

แจกให้คนอื่นใช้: ส่งไฟล์ Setup.exe หรือ zip ทั้งโฟลเดอร์ dist\OpenThaiOCR ส่งไป
เครื่องปลายทางแตก zip แล้วดับเบิลคลิก OpenThaiOCR.exe ได้เลย ไม่ต้องติดตั้ง Python
(ต้องส่งทั้งโฟลเดอร์ ส่งแค่ไฟล์ .exe ไฟล์เดียวจะเปิดไม่ได้)


สร้างสำหรับ Mac ชิป M (ต้องทำบนเครื่อง Mac เท่านั้น)
---------------------------------------------------------------------
1. ติดตั้ง Python 3.12 จาก https://www.python.org/downloads/macos/
2. เปิด Terminal ในโฟลเดอร์นี้ แล้วพิมพ์   bash build_mac.sh
3. ได้โปรแกรมที่  dist/OpenThaiOCR.app  และตัวติดตั้ง  dist/OpenThaiOCR_mac.dmg
   (เปิด .dmg แล้วลาก OpenThai OCR ไปใส่โฟลเดอร์ Applications)

เปิดครั้งแรกบน Mac: macOS จะบล็อกเพราะโปรแกรมไม่ได้ลงทะเบียนกับ Apple
  ให้คลิกขวาที่ OpenThaiOCR.app > Open > Open
  ถ้ายังไม่ได้ ไปที่ System Settings > Privacy & Security > กด Open Anyway


สร้างบนคลาวด์ GitHub (ไม่ต้องมีเครื่อง Mac)
---------------------------------------------------------------------
อัปโหลดโฟลเดอร์นี้ขึ้น GitHub (รวมโฟลเดอร์ .github) แล้วไปที่แท็บ Actions
> Build OpenThai OCR > Run workflow  รอประมาณ 10 นาที
จะได้ทั้ง OpenThaiOCR_win และ OpenThaiOCR_mac ให้ดาวน์โหลดในหัวข้อ Artifacts


วิธีใช้
---------------------------------------------------------------------
1. เพิ่มไฟล์ หรือเพิ่มทั้งโฟลเดอร์ (รองรับ PDF, JPG, PNG, TIFF หลายหน้า, BMP, WEBP)
   หรือลากไฟล์มาวางในหน้าต่างโปรแกรม / บนไอคอน OpenThaiOCR.exe
2. เลือกผลลัพธ์ที่ต้องการ
   - PDF ค้นหาข้อความได้ : หน้าตาเหมือนต้นฉบับทุกอย่าง แต่กด Ctrl+F ค้นหา / คัดลอกข้อความได้
                           ชื่อไฟล์ลงท้ายด้วย _ocr.pdf
   - .txt                 : ข้อความล้วน แยกตามหน้า
   - .docx                : Word ฟอนต์ TH Sarabun New 16 กระดาษ A4 แยกหน้าละ 1 หน้า
   ถ้าไม่ติ๊กเลยสักอย่าง = อ่านอย่างเดียว ไม่บันทึกไฟล์
3. กด "เริ่มแปลง"  อ่านเสร็จแล้วข้อความจะแสดงในแท็บ "ข้อความ"
   - กด "คัดลอกทั้งหมด" หรือลากคลุมบางส่วนแล้วกด Ctrl+C
   - แถบสีเหลือง = บรรทัดที่โมเดลมั่นใจต่ำกว่า 90% ควรตรวจ


อ่านจากภาพหน้าจอ (เร็วที่สุด)
---------------------------------------------------------------------
1. แคปหน้าจอส่วนที่ต้องการ   Windows: Win+Shift+S   Mac: Cmd+Ctrl+Shift+4
2. กลับมาที่โปรแกรม กด Ctrl+V (Mac: Cmd+V)
3. ข้อความจะแสดงในแท็บ "ข้อความ" และถูกคัดลอกให้อัตโนมัติ นำไปวางที่อื่นได้ทันที
ใช้กับหน้าจอระบบต่าง ๆ, PDF ที่ห้ามคัดลอก, รูปในไลน์ ฯลฯ

ผลลัพธ์จะอยู่ในโฟลเดอร์ OCR_output ข้างไฟล์ต้นฉบับ (หรือโฟลเดอร์ที่เลือกเอง)
ไฟล์ชื่อซ้ำจากรอบก่อนจะถูกเขียนทับ


คำแนะนำ
---------------------------------------------------------------------
- ความละเอียด 200 dpi พอสำหรับเอกสารทั่วไป ถ้าตัวหนังสือเล็กมาก (เช่น หมายเหตุท้ายตาราง) ใช้ 300
- "ใช้ CPU" = จำนวนหน้าที่ทำพร้อมกัน แต่ละ core ใช้ RAM ประมาณ 450 MB
  เครื่อง RAM 8 GB แนะนำไม่เกิน 4
- PDF ที่สร้างจาก Word/Excel (ไม่ใช่สแกน) มีข้อความอยู่แล้ว โปรแกรมจะดึงข้อความเดิมมาใช้
  ซึ่งแม่นยำกว่า OCR (ปิดได้ในหน้าตั้งค่า)
- บรรทัดที่ "ควรตรวจ" ในหน้าบันทึก คือบรรทัดที่โมเดลมั่นใจต่ำกว่า 90% ควรตรวจทานก่อนใช้งานจริง


ข้อจำกัดของโมเดล
---------------------------------------------------------------------
- อ่านได้เฉพาะตัวพิมพ์ไทย/อังกฤษ ลายมือเขียนอ่านได้ไม่ดี
- ไม่ได้แยกตารางเป็นช่อง ๆ ตารางจะออกมาเป็นข้อความเรียงตามแถว
- ตราประทับ/ตรายาง จะถูกอ่านออกมาเป็นข้อความด้วย
- ฟอนต์ตกแต่งแปลก ๆ อาจอ่านผิด


ปัญหาที่พบบ่อย
---------------------------------------------------------------------
- Windows แจ้ง "Windows protected your PC" : กด More info > Run anyway
  (เพราะ exe ไม่ได้เซ็นดิจิทัล) ถ้าเป็นเครื่องหน่วยงาน อาจต้องให้ IT อนุญาต
- build.bat ล้มเหลวตอนโหลด : ตรวจว่าต่ออินเทอร์เน็ตได้ และไม่ถูก proxy บล็อก huggingface.co / pypi.org
- อยากทดลองโดยไม่สร้าง exe : หลังรัน build.bat ถึงขั้นที่ 3 แล้ว พิมพ์
      .venv\Scripts\python app.py
